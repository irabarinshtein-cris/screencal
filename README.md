# СкринКалендарь

Android-приложение: скрин расписания → события в календаре телефона → ответ «когда я свободен».
Работает полностью на телефоне, без компьютера и сервера. Распознавание по умолчанию офлайн.

## Что умеет
- **Скрин**: кнопка «Выбрать скрин» или «Поделиться → В календарь» из галереи. Приложение распознаёт дату, день недели, время и событие, показывает карточки для проверки и правки, затем «Добавить в календарь».
  - Дата из строки-заголовка («Понедельник 19.10», «20 октября») применяется к событиям ниже.
  - Понимает форматы `17.10`, `17.10.2026`, `17 октября`, `пн`/`понедельник`, `сегодня`/`завтра`, `10:00-11:30`, `10.00–11.30`, `с 10:00 до 11:30`.
  - Нет времени окончания → событие длится 1 час. Повторная отправка того же скрина дублей не создаёт.
- **Свободно**: вопрос текстом («когда я свободен 20–22 октября?», «завтра», «в пятницу», «на неделю») или кнопки и выбор дат. Свободным считается окно **от 60 минут** в рамках дня 08:00–22:00 (меняется в настройках). Учитываются все видимые календари телефона.
- **Настройки**: режим распознавания, календарь для записи, рамки дня, минимальное окно.

## Режимы распознавания
| Режим | Интернет | Точность |
|---|---|---|
| Офлайн (Tesseract, rus+eng) — по умолчанию | не нужен | хорошо на чётких скринах |
| Claude API | нужен + API-ключ | лучше на таблицах и сложной вёрстке |

## Как получить APK (один раз)
**Вариант A — без компьютера, через GitHub Actions**
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки, включая скрытую папку `.github`.
2. Откройте вкладку **Actions** → **Build APK**. Сборка запустится сама после загрузки, либо нажмите **Run workflow**.
3. Примерно через 5–8 минут скачайте артефакт **ScreenCal-apk** (zip с `app-release.apk`), установите его на телефон и разрешите установку из неизвестных источников.

**Вариант B — Android Studio**: File → Open → папка `ScreenCal` → Run, или Build → Build APK(s).

При первом запуске приложение запросит доступ к календарю. События записываются в выбранный календарь. Если календаря нет, создаётся локальный «Мои планы».

## Структура
- `ScheduleParser.kt` — разбор текста расписания и дат в вопросе
- `Ocr.kt` — офлайн-OCR (Tesseract4Android, данные в `assets/tessdata`)
- `ClaudeVision.kt` — распознавание через Claude API
- `CalendarRepo.kt` — запись в календарь и чтение занятости
- `FreeTime.kt` — расчёт свободных окон
- `MainActivity.kt` — интерфейс (Jetpack Compose)
