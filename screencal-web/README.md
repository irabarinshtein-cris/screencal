# СкринКалендарь (веб-версия)

Кроссплатформенное приложение: Android, iPhone, ПК. Работает в браузере и ставится иконкой на главный экран.

- **Вход через Google.** События записываются прямо в ваш Google Календарь и видны на всех устройствах.
- **Скрин → события.** Таблица пар (колонки — дни) или лента записей с датами. Распознавание идёт офлайн на устройстве или через GigaChat, если он настроен.
- **Поле «Дописать к скрину».** Например: «повторять каждую неделю до 20 декабря», «это нечётная неделя, №9». Можно писать и без скрина: «Бассейн по вторникам 19:00–20:00 каждую неделю до конца декабря».
- **Режимы «Расписание пар» и «Разовые».**
  - Пары повторяются раз в 2 недели (чётная и нечётная неделя), пока не загрузите новое расписание.
  - Пометки «(2–16 нед.)» задают конец повтора, «(на 8 нед.)» — одно занятие. Зачёты и экзамены ставятся разово.
  - Новое расписание обрывает прежнее для той же недели (чёт/нечёт), дублей не будет.
- **Ручной ввод и повтор в каждой карточке:** ежедневно, еженедельно, раз в 2 недели, ежемесячно, ежегодно, с датой окончания или бессрочно.
- **Вкладка «Свободно».** Окна от часа (настраивается) по данным Google Календаря с учётом всех повторов.
- **Кнопка «Добавить в календарь»** закреплена в правом нижнем углу.
- **«Поделиться → СкринКалендарь»** из галереи работает на Android после установки приложения.

## Запуск: 4 шага (один раз, около 30 минут)

### 1. Сайт на GitHub Pages
1. На github.com: **+ → New repository**, имя `screencal-web`, тип **Public**, галочки не ставить → **Create repository**.
2. Нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки, включая папки `vendor`, `tessdata`, `icons`, `gigachat-proxy`. Затем **Commit changes**.
   Проверьте, что `index.html` лежит в корне репозитория, а не во вложенной папке.
3. **Settings → Pages**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/screencal-web/`.

### 2. Вход через Google (Client ID)
1. Откройте https://console.cloud.google.com и создайте проект, например «screencal».
2. **APIs & Services → Library** → найдите **Google Calendar API** → **Enable**.
3. **Google Auth Platform** (или **OAuth consent screen**):
   - тип **External**, название приложения и ваша почта;
   - в разделе **Audience → Test users** добавьте свой Gmail.
4. **Clients → Create client**:
   - тип **Web application**;
   - в **Authorized JavaScript origins** добавьте `https://ВАШ_ЛОГИН.github.io` (без `/screencal-web` и без слеша в конце);
   - нажмите **Create** и скопируйте **Client ID**, он вида `…apps.googleusercontent.com`.
5. На GitHub откройте файл `config.js`, нажмите ✏️, вставьте Client ID в `googleClientId: '…'` и сохраните (**Commit changes**).

При первом входе Google покажет «Приложение не проверено». Для личного приложения это нормально: нажмите **Дополнительно → Перейти на сайт**.

### 3. Ключ GigaChat
1. Откройте https://developers.sber.ru, раздел **GigaChat API**, и войдите через Сбер ID.
2. Создайте проект для физлица и получите **Ключ авторизации** (Authorization key).

### 4. Функция-прокси в Yandex Cloud
GigaChat нельзя вызывать прямо из браузера: мешают сертификат Минцифры и CORS, а ключ нельзя показывать в коде сайта. Поэтому запросы идут через маленькую функцию, у неё есть бесплатный месячный лимит.

1. Откройте https://console.yandex.cloud, при первом входе создайте платёжный аккаунт.
2. **Cloud Functions → Создать функцию**, имя `screencal-gigachat` → **Создать**.
3. На странице функции включите **Публичная функция**.
4. **Редактор**:
   - среда **Node.js 22** (или 18);
   - способ — **Редактор кода**, создайте файл `index.js` и вставьте туда содержимое `gigachat-proxy/index.js`;
   - **Точка входа:** `index.handler`;
   - **Таймаут:** `60` секунд, **Память:** `256 МБ`.
   - **Переменные окружения:**

     | Переменная | Значение |
     |---|---|
     | `GIGACHAT_AUTH_KEY` | ключ авторизации из шага 3 |
     | `APP_PASSWORD` | придумайте пароль, чтобы чужие не тратили ваш лимит |
     | `ALLOWED_ORIGIN` | `https://ВАШ_ЛОГИН.github.io` |

   - нажмите **Сохранить изменения**.
5. Скопируйте **Ссылку для вызова** вида `https://functions.yandexcloud.net/…`.
6. В приложении откройте **Настройки → Нейросеть GigaChat**, вставьте адрес и пароль и нажмите **Проверить связь**.

Дополнительно, для строгой проверки сертификата Сбера: скачайте корневой сертификат Минцифры с gosuslugi.ru/crt и вставьте его текст (PEM) в переменную `GIGACHAT_CA_PEM`. Без неё проверка сертификата Сбера отключена.

Модель по умолчанию — `GigaChat-2-Max`. Её можно сменить переменной `GIGACHAT_MODEL`.

## Установка на телефон
- **Android (Chrome):** откройте сайт → меню ⋮ → **Установить приложение** или **Добавить на главный экран**. После этого в галерее появится **Поделиться → СкринКалендарь**.
- **iPhone (Safari):** **Поделиться → На экран «Домой»**.
- **ПК:** значок установки в адресной строке Chrome или Edge. Скрин можно вставить через Ctrl+V.

## Как пользоваться
1. Войдите через Google (кнопка вверху).
2. Выберите режим: **Расписание пар** или **Разовые**. Он выбирается и сам: таблица пар — расписание, лента — разовые.
3. Загрузите скрин и при необходимости допишите текст. Нажмите **Распознать**.
4. Проверьте карточки. Для таблицы без дат проверьте неделю и № учебной недели.
5. Нажмите кнопку в правом нижнем углу.

Чётную и нечётную неделю загружайте двумя скринами, каждая станет своим повторяющимся расписанием.

|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс, вход Google, Google Календарь |
| `parser.js` | разбор расписаний, недели, повторы, свободные окна |
| `config.js` | Client ID Google и адрес прокси |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка и «Поделиться» |
| `vendor/tesseract`, `tessdata/` | офлайн-распознавание (рус + англ) |
| `gigachat-proxy/index.js` | функция для Yandex Cloud |
